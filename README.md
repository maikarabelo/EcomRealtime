# EcomRealtime (SQL-only)
Real-time processing demo: Azure Event Hubs → Azure Functions (.NET 8 isolated) → Microsoft SQL Server; ASP.NET Core MVC dashboard on Azure App Service.

Important: This project is SQL-only. It uses Microsoft SQL Server (SSMS-managed).

See Ecom.Realtime.Func/local.settings.json.example and Ecom.Realtime.Mvc/appsettings*.json for configuration.
